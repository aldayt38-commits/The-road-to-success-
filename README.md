# طريق النجاح — حادي عشر علمي · غزة

منصة جوال للرزم التعليمية. افتحها من الهاتف.

## رابط GitHub Pages

بعد رفع المستودع وتفعيل Pages يصير الرابط:

`https://USERNAME.github.io/tareeq-najah/`

## تفعيل الصفحات (مرة واحدة)

1. المستودع **Public**
2. Settings → Pages → Branch: `main` / folder: `/ (root)` → Save
3. انتظر دقيقة وافتح الرابط من الجوال

الملف `.nojekyll` موجود حتى يشتغل الموقع كما هو.
